# Моя рутина

Личный сайт, на котором видно весь мой день: режим, сон, еда, тренировки, учёба, смены и деньги. Всё в одном файле `index.html`, в космическом стиле, с анимациями.

## Разделы

Каждый раздел — отдельный экран со своей космической сценой и вкладками сверху.

| Раздел | Вкладки |
| --- | --- |
| Сегодня | Сегодня (что делать: список дел дня собирается сам, быстрое добавление) · Неделя · Режим · Сон |
| Еда | Сегодня (из того, что есть дома: расчёт калорий и белка, раскладка по приёмам) · План (когда магазин, заготовки, что взять с собой) · Меню · Заготовки · Покупки |
| Спорт | Сегодня · Программа · Вес |
| Учёба | Дедлайны · Календарь (академический календарь 2026–2027) · Как учиться |
| Работа | Смены · Ночи · Вставить график (из рабочего чата) |
| Деньги | Сейчас · Траты · Зарплата (план по периодам и распределение) · Подушка · Сетап |
| Цели | Прогресс · Награды · Вопросы · Данные (резервная копия, файл календаря) |

Адрес запоминает раздел и вкладку, например `#food/plan`.

На github.io сайт ставится на главный экран как приложение и работает без интернета (`manifest.webmanifest`, `sw.js`).

Сайт сам определяет тип дня (пары, ночная смена, после смены, выходной) и строит под него окна сна, еду и тренировку. Тяжёлые ночи (перед парой в 08:30) подсвечиваются заранее.

## Как открыть

- Скачать `index.html` и открыть в браузере. Данные сохраняются в этом браузере (localStorage).
- В Claude сайт открыт как артефакт «Моя рутина»: там данные синхронизируются между устройствами.
- Чтобы был свой адрес в интернете: Settings → Pages → Branch `main`, папка `/ (root)` → Save. Через минуту сайт будет на `https://leadboost-fast.github.io/myroutine-/`.
