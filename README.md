# Моя рутина

Личный сайт, на котором видно весь мой день: режим, сон, еда, тренировки, учёба, смены и деньги. Всё в одном файле `index.html`, в космическом стиле, с анимациями.

## Разделы

| Раздел | Что внутри |
| --- | --- |
| День | Процент дня, что важно сейчас, советы помощника и режим на сегодня, собранный по сменам и парам |
| Ритм | Привычки, питание с белком, тренировка дня, вес и линия плана |
| Учёба | Дедлайны (выполненные затягивает в чёрную дыру) |
| Работа | Календарь смен 20:00–08:00, оплата за смену, прогноз зарплаты |
| Деньги | Сколько можно тратить в день до поступления, обязательные платежи, траты по категориям |
| План | План до 30 июня 2027: неделя, режим по типам дней, сон, еда с заготовками и списком покупок, программа тренировок, распределение зарплаты, подушка, учёба, цели по месяцам, вопросы |

Сайт сам определяет тип дня (пары, ночная смена, после смены, выходной) и строит под него окна сна, еду и тренировку. Тяжёлые ночи (перед парой в 08:30) подсвечиваются заранее.

## Как открыть

- Скачать `index.html` и открыть в браузере. Данные сохраняются в этом браузере (localStorage).
- В Claude сайт открыт как артефакт «Моя рутина»: там данные синхронизируются между устройствами.
- Чтобы был свой адрес в интернете: Settings → Pages → Branch `main`, папка `/ (root)` → Save. Через минуту сайт будет на `https://leadboost-fast.github.io/myroutine-/`.

## Данные

Цены в списке покупок — мониторинг супермаркетов Астаны, ноябрь 2026. Их можно поменять прямо на сайте: «План» → «Еда» → «Изменить цены».
